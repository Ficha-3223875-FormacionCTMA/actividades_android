# Pruebas y evidencias a tomar

Estas evidencias no se pueden fabricar dentro del ZIP porque deben mostrar la ejecución real en el entorno del aprendiz.

## Semana 1
- Captura de proyecto ejecutándose.
- Captura de estructura Android Studio.
- Captura de Build/Logcat interpretada.
- Captura de `git status` sin archivos generados ni secretos.

## Semana 2
- Salida de casos de estado, promedio, urgentes y validación.
- Captura o registro de modificación de una regla.

## Semana 3
- Preview normal.
- Preview con título largo/progreso límite.
- Lista vacía.
- Fuente aumentada.
- Ancho ampliado.
- Hallazgo de prueba cruzada → corrección → nueva prueba.

## Semana 4
- Formulario válido.
- Error de título.
- Error de descripción.
- Error de fecha.
- Error de progreso.
- Rotación con borrador conservado.
- Lista → Crear → Lista.
- Lista → Detalle → Atrás.
- ID inexistente.
- Doble toque en Guardar.
