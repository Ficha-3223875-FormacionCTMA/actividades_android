# Sprint Review y Retrospective

## Sprint Review
Demostrar en vivo:
1. Lista de actividades.
2. Crear una actividad válida.
3. Una validación negativa.
4. Detalle y edición.
5. Búsqueda.
6. Una prueba de accesibilidad/fuente aumentada.
7. Resultados reales de pruebas.
8. Defectos relevantes, si los hubo.
