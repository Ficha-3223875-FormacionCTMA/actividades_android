# Alcance inicial — Semana 1

## Problema
Los aprendices administran actividades, enlaces, evidencias y fechas en diferentes canales. Esto puede producir olvidos, duplicación y poca trazabilidad. Mi Formación CTMA propone centralizar la consulta y el seguimiento básico de actividades formativas en una aplicación Android sencilla, evolucionable y verificable.

## Usuarios
- **Aprendiz:** necesita consultar compromisos y registrar su avance para organizar su proceso formativo.
- **Instructor:** necesita comunicar actividades y criterios para mejorar la trazabilidad formativa.

## Historias de usuario
1. Como aprendiz, quiero consultar mis actividades, para saber qué compromisos tengo pendientes.
2. Como aprendiz, quiero registrar y actualizar el progreso, para conocer cuánto he avanzado.
3. Como instructor, quiero que cada actividad muestre fecha, estado y prioridad, para comunicar claramente los criterios del compromiso.

## Criterios de aceptación
- La lista muestra título, estado, progreso y fecha cuando existe.
- El formulario no permite guardar un título vacío, menor de 3 o mayor de 80 caracteres.
- Al abrir una actividad se muestra su detalle y se puede regresar a la lista.
